# Advanced Java Technologies Laboratory

This repository contains Java practical programs completed as part of the **Advanced Java Technologies (AJT)** laboratory.

The practicals are implemented according to the laboratory manual and syllabus. Each folder represents an individual experiment performed during the course.

## Practicals

- Java Servlet to Handle HTTP Requests
- User Session Management using HttpSession
- JSP Form Handling
- Database-Driven Web Application using JSP, Servlet and JDBC
- Java Mail API
- Real-Time Chat Application using WebSocket
- Hibernate CRUD Operations
- Hibernate Caching
- REST API using Spring Boot
- JWT Authentication using Spring Security
- Product Management Microservice
- Deploy Spring Boot Application using Docker
